# 🏮 2026 군산 시간여행축제 & 비응항 바다낚시 1박 2일 가족여행 가이드

5인 가족(아빠, 엄마, 중1, 초5, 초2)을 위한 맞춤형 1박 2일 군산 여행 모바일 플래너 웹페이지입니다.  
가족 구성원들과 모바일 브라우저로 손쉽게 확인하고 카카오톡/문자로 일정을 공유할 수 있도록 제작되었습니다.

---

## 📅 여행 개요
- **일정**: 2026년 10월 4일(일) ~ 10월 5일(월) (1박 2일)
- **출발**: 10월 4일(일) 13:00 전주 송천동 출발 (자동차 약 45분 소요)
- **인원**: 5명 (아빠, 엄마, 중1 남, 초5 여, 초2 남)
- **핵심 테마**: 비응항 방파제 생활 바다낚시 + 2026 군산 시간여행 축제 + 근대역사문화 탐방 + 군산 미식 기행

## 🗺️ 전체 일정 요약

- **14:00** : 군산 비응항 도착 & 낚시용품 대여 (군산낚시터미널)
- **14:30 ~ 17:00** : 비응항 방파제/내항 안전 구역 온가족 생활낚시 (망둥어, 우럭, 노래미)

- **21:45** : 숙소 체크인 (여미랑 / 은파팰리스 / 에이본 등) 및 휴식

### DAY 2 · 10월 5일(월)
- **08:30 ~ 09:30** : 아침 식사 : **한일옥** (맑은 한우 소고기무국)

- **10:30 ~ 12:30** : **군산 시간여행 축제 주간 체험** (개화기 의상 체험, 밀서 방탈출 미션, 위봉함 관람)
- **12:45 ~ 14:00** : 점심 식사 : **빈해원** (100년 전통 문화재 중식당 물짜장·탕수육) & **이성당** 빵 포장
- **14:30** : 전주 송천동으로 여유롭게 귀가 출발 (약 45분) ➔ **15:30 전주 도착**
